## The five things that win this
1. **Onboard all ~50 cameras**, not six — cheapest large gain available
2. **Win the vehicle-trace moment on recall** — grammar-constrained decode + confusion-space matching + Re-ID bridging
3. **Measurements, not claims** — a real load test and a ₹-crore cost table
4. **Evidence integrity + DPDP privacy** — uncontested ground, and NFSU is on the panel
5. **Make the mandatory registry the crown jewel** — cameras that profile themselves
